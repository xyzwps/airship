Airship 是一个 Electron app runtime

自己写的小工具，每一个都得重搭一套 Electron 壳：窗口、标题栏、主题、留白、能力授权、打包安装。 Airship 把这一层沉进一个装一次大家共用的 runtime——应用只剩清单、一个组件、一张图标， 八个预置应用和外面写的应用跑的是同一份 runtime。 

// src/apps/life/main.tsx —— 一个应用入口脚本的全文
import { createAirshipApp } from '@airship/sdk'
import { app } from './app'
import LifeApp from './LifeApp'

createAirshipApp({ meta: app, component: LifeApp, icon: './icon.svg' })
runtimejust build-runtime→airship-runtime-Setup-<版本>-x64.exe每机一份，装进 Program Files
一个应用just app-installer <id>→<id>-Setup-<版本>.exe每用户，装完双击快捷方式直接开窗口
