# tray

## Purpose
系统托盘：全局只有一个图标，多个应用可能都想要它，所以"谁占着"是一条用户可见的规矩。

### Requirement: 一个托盘图标，占用者唯一
#### Scenario: TR-001 谁设置的就是谁占着
- **WHEN** 某应用设了一个带提示文字的托盘状态
- **THEN** 壳记下这个应用是占用者，提示文字与图标按它给的来

#### Scenario: TR-002 只有占用者能清掉托盘
- **WHEN** 另一个应用（或占用者自己）调清理
- **THEN** 别人调是空操作——图标仍在、占用者不变；占用者调才真的把图标撤掉

#### Scenario: TR-003 退出时不分归属一律清掉
- **WHEN** 应用要退出
- **THEN** 托盘图标被销毁，占用关系清空

### Requirement: 提示文字与图标
#### Scenario: TR-004 提示文字过长被截到 120 字
- **WHEN** 应用给一句很长的提示文字
- **THEN** 托盘上显示的是前 120 字，不是一整段灌进系统提示

#### Scenario: TR-005 带数字的图标由应用画好交上来，画不了就用壳默认的
- **WHEN** 应用给了 16×16 的 PNG dataURL
- **THEN** 托盘用它；没给（或给的是空图）就用壳自带的默认图标，提示文字仍然更新
- **AND** 只给徽标文字（如 `3/5`）时不报错，图标保持默认——位图上的字得渲染侧画

#### Scenario: TR-006 右键菜单里有点得动的两项
- **WHEN** 打开托盘右键菜单
- **THEN** 读得到「打开飞船」与「退出」两项，第一行是占用者那句提示且点不动（只是说明）

### Requirement: 点击只回到占用那个应用
#### Scenario: TR-007 点托盘 → 事件只投占用窗口
- **WHEN** 用户点托盘图标
- **THEN** 只有占用那个应用的窗口收到 `tray:click`，其他应用与启动器一条都收不到

#### Scenario: TR-008 默认把启动器唤到前台，应用可以自己不要
- **WHEN** 用户点托盘
- **THEN** 没写 `focusOnClick: false` 时启动器被唤到前台；写了 false 就不动启动器
- **AND** 占用者自己已经不在（没设过托盘）时点它什么也不发生
