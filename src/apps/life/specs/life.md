# life

## Purpose

生命游戏：一张 n×n 的网格按 B3/S23 一代一代跑，界面上给得出经典图形，也画得出自己的初始图形。
这本册子钉的是尺寸口径、推演结果与"点了以后变成什么"；真画出来看不看得见网格范围归 `just shot`。

### Requirement: 世界只有网格，一格多大由可视区算

依据：这里没有"画布"那一层，也没有"缩放档"那一族键——只有格数（玩家选）与一格的屏幕像素（可视区算）两件事。

#### Scenario: LF-001 状态行念得出此刻的网格与一格多大
- **WHEN** 打开生命游戏
- **THEN** 状态行读得到「网格 100×100」，并读得到「一格 N 像素」这一截
- **AND** 界面上不再出现"画布 1000×1000"那类说法

#### Scenario: LF-026 整张网格铺满可视区的短边，长边那一截空白分到两侧
- **WHEN** 看网格区与界面上的档位键
- **THEN** 画布的边长等于「格数 × 状态行念出的那一格像素」，横竖同一个数
- **AND** 它落在网格区正中——空白不堆在右下角
- **AND** 界面上没有一排"像素档"键，也没有「适应」那颗（缩放整族删了）

### Requirement: 网格大小是三档，换档就重开一张

#### Scenario: LF-005 换网格大小是重开：新格数、第 0 代、跑着的停下
- **WHEN** 先点「200×200」
- **THEN** 状态行同时读到「网格 200×200」与「第 0 代 · 存活 5」，播放不再是选中态
- **AND** 界面上读得到「换成 200×200 的网格，从第 0 代开始」
- **AND** 三档（100 / 200 / 300）里亮着的永远是当前这一档

#### Scenario: LF-006 图形库里的每一项在最小那一档网格上也放得下
- **WHEN** 逐个看图形库每一项的外框
- **THEN** 每一项都不超过 100×100 格，且都不是空图形
- **AND** 五组里没有任何一组是空的

### Requirement: 规则是 B3/S23，越界怎么数邻居由边界那一档定

依据：贴边的格子数不到外面的东西，是"墙"；从对边接上，是"环绕"。两档都要——环绕让飞船永远走得下去，
墙让"撞碎"这一课看得见。默认环绕。

#### Scenario: LF-007 墙那一档下，左上角那三格只数得到网格里的邻居
- **WHEN** 边界选「墙」，把活格摆在 (0,0)、(1,0)、(0,1) 推一代
- **THEN** (0,0) 数到 2 个邻居，按"2 或 3 个就活"留下
- **AND** 网格外不算格子，也没有从右下角绕回来的邻居

#### Scenario: LF-008 三格一线横一下竖一下，2 代回到原样
- **WHEN** 摆一行三格，连着推两代
- **THEN** 第 1 代是一列三格，第 2 代回到一行三格

#### Scenario: LF-009 两格挨着活不成，四格方块永远原样
- **WHEN** 只摆两格相邻的活格推一代；再摆 2×2 方块推十代
- **THEN** 两格都死光（各只有一个邻居），方块一格没动

#### Scenario: LF-028 环绕那一档下，贴边的格子从对边接上
- **WHEN** 边界选「环绕」，只在右下角 (99,99) 摆一格活格
- **THEN** 左上角 (0,0) 数到 1 个邻居——那就是绕过来的 (99,99)
- **AND** 换到「墙」那一档，同一个位置数到 0 个

#### Scenario: LF-029 边界有两颗键，默认亮着环绕，换档不清盘也不动世代
- **WHEN** 摆几格、单步两代，再点「墙」
- **THEN** 「墙」是选中态、「环绕」不是，状态行仍是刚才那个世代与那些存活格
- **AND** 打开界面时亮着的是「环绕」

#### Scenario: LF-030 同一只滑翔机：环绕下走两百代还是五格，墙下会碎在边上
- **WHEN** 把滑翔机摆在网格正中，两档各推两百代
- **THEN** 环绕那一档数下来仍是 5 格（它从对边绕回来，永远走下去）
- **AND** 墙那一档数下来不是 5 格——它撞在右下角的边上碎了

### Requirement: 世代怎么往前走，界面上看得见

#### Scenario: LF-010 单步一次，世代加一且画面真的推进一代
- **WHEN** 摆一个三格一线，点「走一代」
- **THEN** 状态行读到「第 1 代 · 存活 3」，再点一次是「第 2 代」

#### Scenario: LF-011 播放按档子的节奏自己走，暂停停在当前代
- **WHEN** 点播放，等过半秒；再点一次
- **THEN** 世代已经往前走了一步以上
- **AND** 再等半秒，世代停在按下去那一刻的数上不再走

#### Scenario: LF-012 全灭了不用人守着，它自己停下并说一句
- **WHEN** 清空网格后只涂一格活格，点播放等它死光
- **THEN** 状态行读到「存活 0」，播放那颗不再是选中态
- **AND** 界面上读得到「全灭了，停下来」

### Requirement: 初始图形完全由玩家画

#### Scenario: LF-013 按下去那格是死的，这一笔一路涂活
- **WHEN** 点「清空网格」，从 (1,1) 按住拖到 (3,1)
- **THEN** 状态行读到「存活 3」，世代仍是第 0 代
- **AND** 中间那一格 (2,1) 也在——快速拖动只给首尾两个点，线不能断

#### Scenario: LF-014 按下去那格是活的，这一笔就是擦
- **WHEN** 清空后涂出 (1,1) 到 (3,1) 三格，再从 (2,1) 按住拖到 (3,1)
- **THEN** 状态行读到「存活 1」——这一笔只擦掉按下去那格与拖过的两格

#### Scenario: LF-015 清空网格把世代与跑着的键一起归位
- **WHEN** 摆几格并点播放，再点「清空网格」
- **THEN** 状态行读到「第 0 代 · 存活 0」，播放不再是选中态
- **AND** 界面上读得到「网格清空了」

#### Scenario: LF-016 随机那一下从第 0 代开始，同一种子给同一张图
- **WHEN** 点「随机」
- **THEN** 状态行读到「第 0 代」且存活格数大于 0，跑着的键停下来
- **AND** 拿同一个种子与同一个密度铺两次，逐格一样

### Requirement: 经典图形放得进、说得出，说明书不许凭记忆写

依据：每一个形状都有出处（公开教程的坐标，或在小窗口里穷举所有不动点摆法测出来的），
每一个数字都是在这块网格上量出来的。写错数字，用例就红。

#### Scenario: LF-017 图形库是手风琴：五组标题依次在，一次只展开一组
- **WHEN** 打开生命游戏
- **THEN** 依次读得到「静止体」「振荡器」「飞船」「长寿种子」「机枪」五个组头，每个都带着自己的个数
- **AND** 只有「静止体」那一组是展开的，其余四组的图形在界面上读不到

#### Scenario: LF-018 说明书里的周期在推演里真成立
- **WHEN** 逐个把静止体与振荡器放到网格上量周期
- **THEN** 方块、小船、蜂房、面包周期都是 1；闪烁灯、蟾蜍、信标是 2；脉冲星是 3；十五棒是 15

#### Scenario: LF-019 飞船说明书写的位移是真的
- **WHEN** 量滑翔机与轻量飞船一个周期的位移
- **THEN** 滑翔机 4 代往右下走 1 格，轻量飞船 4 代向右走 2 格

#### Scenario: LF-020 挣扎者会死干净，两粒种子跑很久还在变
- **WHEN** 分别量挣扎者、橡果与 R 五连块
- **THEN** 挣扎者到第 130 代一个不剩
- **AND** 橡果与 R 五连块到第 300 代还活着，200 代以内没有重复过自己

#### Scenario: LF-021 脉冲星的活格数按 48 → 56 → 72 循环
- **WHEN** 数脉冲星前四代的活格数
- **THEN** 读到 48、56、72、48

#### Scenario: LF-022 机枪每 30 代多出一只滑翔机，且落在左上角走得开
- **WHEN** 按图形库给的落点把机枪放到 100×100 的网格上，数第 30、60、90 代
- **THEN** 活格数依次是 41、46、51——每 30 代正好多 5 格（一只滑翔机）
- **AND** 它的落点贴着左上角，不是网格正中

#### Scenario: LF-023 点图形是换一个起点：网格上只剩它、世代归零、跑着的停下
- **WHEN** 先点「方块」让它跑几代，再点「滑翔机」
- **THEN** 状态行读到「第 0 代 · 存活 5」——方块那四格不在了，网格上只有滑翔机
- **AND** 播放不再是选中态，界面上读得到「换上「滑翔机」，从第 0 代开始」

#### Scenario: LF-027 点组头换展开的那一组，再点一次收起来
- **WHEN** 点「飞船」那一行的组头
- **THEN** 「滑翔机」与「轻量飞船」念得出来，「方块」与「闪烁灯」都不再出现
- **AND** 再点一次「飞船」的组头，五组全收起，界面上一个图形项都读不到

### Requirement: 第一次打开就有东西可看

依据：空白网格 + 一排控件是"待办清单"的样子，不是学习工具的样子；先给一只停着的滑翔机，点播放就动。

#### Scenario: LF-024 打开就有一只滑翔机停在第 0 代，不自己跑
- **WHEN** 打开生命游戏
- **THEN** 状态行读到「第 0 代 · 存活 5」，播放那颗不是选中态
- **AND** 点播放走几代，存活格数一直是 5（它会走，不会碎）
