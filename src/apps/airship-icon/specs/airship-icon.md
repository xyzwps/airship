# airship-icon

## Purpose
图标工坊管的是"给一份 SVG，出这两张图"这一件事：`icon.png`（包根那张源图）与 `icon.ico`（外壳那 7 帧）。
一本册子只管这块用户可见的东西——产包与安装期不转格式（AGENTS.md 本机事实），所以"转换"必须发生在应用里，
而应用里出的东西对不对，就看这本册子。像素本身画得好不好归截图走查（`just check-ui`）。

### Requirement: 输入只接 SVG，读不到就说读不到
依据：`docs/apps/icon.md` 那份标准的上游就是一份 SVG；窗口侧拿到盘上的真路径只有一条合法来路
（`dialog.openFiles` 会把选中路径授一次读，见 grants.md），拖进来的 File 对象能不能读出字节是 Electron 的行为，
验不了就不能当它成立（AGENTS.md：没解决就说没解决）。

#### Scenario: IC-001 第一屏读得到三条来路
- **WHEN** 打开这个应用
- **THEN** 界面上读得到「图标工坊」与「选 SVG 文件」
- **AND** 读得到那句「拖一份 .svg 进来、按「选 SVG 文件」，或把源码贴进下面那个框。」

#### Scenario: IC-002 根标签没有 `<svg>` 的就拒在门口
- **WHEN** 往那个框里贴一段没有 `<svg>` 根标签的文本
- **THEN** 错误条原样读得到「那不是 SVG：根标签里没有 <svg>。」
- **AND** 预览那一格仍读得到「还没有可预览的东西」

#### Scenario: IC-003 选了文件，来源那行念得出文件名
- **WHEN** 选中一份写得好的 `.svg`
- **THEN** 界面读得到「来源：demo.svg」
- **AND** 预览那一排出现 15 / 16 / 32 / 64 / 128 / 256 六档

#### Scenario: IC-004 取消选择什么都不改
- **WHEN** 按「选 SVG 文件」后在文件框里取消
- **THEN** 错误条读得到「没选中文件，什么都没改。」
- **AND** 来源那行仍是「来源：还没有」

#### Scenario: IC-005 拖进来那份读不出字节时指回合法来路
- **WHEN** 拖一个内容为空的文件进来
- **THEN** 错误条原样读得到「拖进来的那份读不出字节（这个窗口的 File 对象只是张标签）。请改用「选 SVG 文件」，或把源码贴进下面那个框。」
- **AND** 不静默当成没发生

### Requirement: 原始比例取自 SVG 自己写的那对数
依据：根标签没有可用宽高时图片会按 300×150 的默认盒子画，方图就歪成一条横杠——所以先量出比例、
再把根标签的 width/height 钉成那对数；量不出来时按方图兜底并念出来，别让用户以为丢了东西。

#### Scenario: IC-006 有 viewBox 就读它
- **WHEN** 贴进去的 SVG 写着 `viewBox="0 0 24 24"`
- **THEN** 状态条读得到「原始比例 24 : 24（来自 viewBox）」

#### Scenario: IC-007 只有根标签宽高也认，`px` 后缀也认
- **WHEN** 贴进去的 SVG 没 viewBox、根标签写 `width="96px" height="64px"`
- **THEN** 状态条读得到「原始比例 96 : 64（来自根标签的 width/height）」

#### Scenario: IC-008 两样都没写就按方图并念出来
- **WHEN** 贴进去的 SVG 只写 `<svg xmlns="…">`
- **THEN** 状态条读得到「这份 SVG 没写 viewBox，也没写数字宽高，按 100 × 100 的方图出。」

### Requirement: 出的 icon.png 是一张方图
依据：标准只认包根那一张 PNG；边长由作者填，画布是方的就居中留透明边（contain），不裁不拉伸。

#### Scenario: IC-009 选好落点后，盘上读回来的开头是 PNG 签名
- **WHEN** 边长填 512，按「出 icon.png」并给出落点
- **THEN** 该路径上读得到的字节以 `137 80 78 71 13 10 26 10` 开头
- **AND** 状态条读得到「icon.png 已写到」（后面跟着那个路径）

#### Scenario: IC-010 边长不合范围就不出图
- **WHEN** 边长填 4 再按「出 icon.png」
- **THEN** 错误条原样读得到「PNG 边长要在 8 – 1024 px 之间。」
- **AND** 那一路一个字节都没落到卷上

#### Scenario: IC-011 落点取消就没有文件
- **WHEN** 按「出 icon.ico」后在落点框里取消
- **THEN** 错误条读得到「没选落点，文件没写。」
- **AND** 卷上那个路径读不到任何东西

### Requirement: 出的 icon.ico 是标准那 7 帧
依据：标准形状由仓内 12 张真 ico 实测得出（`docs/apps/icon.md`：7 帧升序、每帧 32 位、帧内是 PNG、
目录里 256 写成 0、planes 为 0），拼完立刻用同一份读回函数自检，界面念的就是读回来的目录。

#### Scenario: IC-012 写完之后从盘上读回目录，7 帧升序且每帧 32 位 PNG
- **WHEN** 给一份好 SVG，按「出 icon.ico」并给出落点
- **THEN** 那个路径上的字节读回 7 条目录项，尺寸依次 16 / 24 / 32 / 48 / 64 / 128 / 256
- **AND** 每一项的位深都是 32，帧内都以 PNG 签名开头

#### Scenario: IC-013 状态条念得出实际帧清单与大小
- **WHEN** 上一那条存成功
- **THEN** 状态条读得到「16/24/32/48/64/128/256，每帧 32 位 PNG」

#### Scenario: IC-014 一帧都没有就不出文件
- **WHEN** 拿空列表去拼 ico
- **THEN** 念出「ico 至少要有一帧。」

#### Scenario: IC-015 同一个尺寸只许一帧
- **WHEN** 拿两帧 32 px 去拼 ico
- **THEN** 念出「同一个尺寸只能有一帧：32 出现了两次」

#### Scenario: IC-016 帧内不是 PNG 就点名第几帧
- **WHEN** 第一帧的字节是一段 JPEG
- **THEN** 念出「第 1 帧（32 px）不是 PNG」

#### Scenario: IC-017 目录写的尺寸与图本身不符就拒
- **WHEN** 声明 32 px 却塞进一张 16 × 16 的 PNG
- **THEN** 念出「第 1 帧写着 32 px，图本身是 16 × 16」

#### Scenario: IC-018 帧尺寸出格就报收到的数
- **WHEN** 拿一帧 300 px 去拼 ico
- **THEN** 念出「帧尺寸要在 1 – 256 px 之间，收到 300」

#### Scenario: IC-019 头对不上的文件不当 ico 读
- **WHEN** 拿一份头字段不是 `0,0,1,0` 的字节去读目录
- **THEN** 念出「这不是 ico：头的保留字节或类型对不上（图标应当是 0,0,1,0）。」

### Requirement: 画不动的那份 SVG 念人话，不静默交一张白图
依据：含 `foreignObject` 或外部引用的 SVG 会污染画布，浏览器不把像素交出来（`toBlob` 直接失败）；
根标签没闭合则是图片本身加载失败。两种都得点名，否则用户拿到一张透明方图还以为是自己的图坏了。

#### Scenario: IC-020 画布交不出像素时念那句原话
- **WHEN** 画一份含 `<foreignObject>` 的 SVG 再按「出 icon.png」
- **THEN** 错误条原样读得到「画不动这份 SVG：它含 foreignObject 或外部引用，浏览器不把像素交出来。」
- **AND** 那个落点路径在卷上读不到东西

#### Scenario: IC-021 SVG 加载不开时念那句原话
- **WHEN** 画一份根标签没闭合的 SVG，加载失败
- **THEN** 错误条原样读得到「这份 SVG 读不开：根标签没闭合，或语法有问题。」
