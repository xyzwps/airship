# wsld-containers

## Purpose
容器台「容器」页左边那一列容器，与点一行之后右边那块详情。
一行只负责认出"是哪个容器"，它完整字段在这本册子里；行上那几颗操作键与操作互斥在
`wsld-container-actions.md`(CA)，「日志」那一侧在 `wsld-logs.md`(WL)。
数据只来自 `wslc list -a --format json`（本机全部容器，含已停止的）。

### Requirement: 打开就把本机容器摆出来
启动即读一次，不必用户点任何东西；一行只留识别信息（名称、状态、镜像），
命令、端口、网络、创建时间、ID 一律进详情看——留在行里只会把左栏撑宽。

#### Scenario: CL-001 启动应用自动读一次
- **WHEN** 本机装有 wslc，打开容器台并停在「容器」页
- **THEN** wslc 那侧收到且只收到 `list -a --format json` 这一条命令
- **AND** 不需要任何点击，本机容器就逐条摆出来，与 `wslc list -a` 看到的对得上

#### Scenario: CL-002 一行只报名称、状态、镜像
- **WHEN** 停在「容器」页看任一行
- **THEN** 那一行读得到容器名称、状态（"运行中"或"已停止"）与镜像名
- **AND** 那一行读不到命令、端口、网络、创建时间与容器 ID

#### Scenario: CL-003 运行中的排前面，同档内按名称
- **WHEN** 本机既有运行中的容器也有已停止的容器
- **THEN** 运行中的那几行排在已停止的行前面
- **AND** 同一档内按名称排，不区分大小写

#### Scenario: CL-004 本机一个容器都没有
- **WHEN** wslc 回的是空文本（本机没有任何容器）
- **THEN** 读得到"本机还没有容器"，界面不出现错误条
- **AND** 汇总读得到"共 0 个容器 · 0 个运行中"

#### Scenario: CL-005 汇总报的是全机的数
- **WHEN** 本机有 N 个容器、其中 M 个在跑，而搜索框里写着词
- **THEN** 顶部读得到"共 N 个容器 · M 个运行中"
- **AND** 这两个数不跟着搜索词变

#### Scenario: CL-006 最近一次刷新看得见
- **WHEN** 列表刚刷成功
- **THEN** 读得到"最近刷新"的时刻，精确到秒
- **AND** 这一屏从头到尾没刷成功过时，那一处读得到"尚未刷新"

### Requirement: 列表靠刷新跟上本机变化
这一页不自己转着读：每次读都要起一个 wslc 进程走一趟引擎。
工具栏留一颗刷新键，操作成功后另有一次自动补刷（见 CA）。

#### Scenario: CL-007 点刷新只发那一条命令
- **WHEN** 点「刷新」那颗键
- **THEN** wslc 那侧新收到一条 `list -a --format json`，不多发别的
- **AND** "最近刷新"的时刻跟着往后走

#### Scenario: CL-008 上一次没读回来不叠加下一次
- **WHEN** 一次读取还没结束，又点了一次「刷新」
- **THEN** 这一轮直接跳过，wslc 那侧不会同时挂着两条 `list`
- **AND** 界面不闪断，行还是原来那几行

### Requirement: 找一个容器不用翻页
搜索只在已经读回来的数据里挑，一次进程都不起。

#### Scenario: CL-009 输入即过滤
- **WHEN** 在搜索框里输入某个容器的名称、镜像名或 ID 的任一片段
- **THEN** 列表立刻只剩匹配的那些行
- **AND** 匹配不区分大小写，也不要求从头开始

#### Scenario: CL-010 过滤不惊动 wslc
- **WHEN** 输入搜索词，又把搜索词删干净
- **THEN** wslc 那侧一条命令都没多收到

#### Scenario: CL-011 一个都没匹配上
- **WHEN** 搜索词把每一行都筛掉了
- **THEN** 读得到"没有匹配的容器"，界面不出现错误条

#### Scenario: CL-012 清空搜索词回到全部
- **WHEN** 把搜索框里的字删干净
- **THEN** 列表回到全部容器，顺序还是运行中的在前

### Requirement: 点一行就是它的详情
一行都没选中时右侧只给一句引导话；选中之后标题、状态与动作键立刻出来。
详情只有「详情」与「日志」两档，不能新建也不能关闭。

#### Scenario: CL-013 还没选容器时右侧只有一句引导
- **WHEN** 进入「容器」页，一行都没点
- **THEN** 右侧读得到"点击左侧的容器查看详情"
- **AND** 这一侧读不到任何字段名，也没有动作键

#### Scenario: CL-014 点一行就把标题与状态摆出来
- **WHEN** 点左侧任一行
- **THEN** 右侧头部读得到那个容器的名称与"运行中/已停止"徽标
- **AND** 头部读得到启动 / 停止 / 重启 / 删除这四颗键

#### Scenario: CL-015 换一行，详情立刻跟着换
- **WHEN** 选中另一行
- **THEN** 右侧整块换成新选中那个容器的内容，不留上一条的名称或字段值

#### Scenario: CL-016 详情分成这几节
- **WHEN** 选中一个容器，停在「详情」这一档
- **THEN** 从上到下读得到「基本信息」「运行状态」「网络」「标签」四节标题
- **AND** 基本信息里有 ID、镜像、命令、创建时间、平台、大小这六项

#### Scenario: CL-017 没有值的字段摆成横杠
- **WHEN** 某个容器没有端口映射、没有网络、没有大小、也没有健康检查
- **THEN** 对应那一项的值读得到"—"，不是空着让人以为渲染坏了

#### Scenario: CL-018 选中的容器在别处被删掉了
- **WHEN** 详情正开着某个容器，刷新之后本机已经没有它了
- **THEN** 右侧读得到"未找到该容器，可能已被删除。"，界面不崩
- **AND** 左侧列表里这一行已经没了

### Requirement: 标签那一长串拆得开
wslc 把标签报成一整条逗号拼接的串，而值自己就可能带逗号
（`com.microsoft.wsl.container.metadata` 那串 JSON 就是）。详情里按"键一行、值一行"摆。

#### Scenario: CL-019 一个标签占两行
- **WHEN** 某容器带着形如 `com.example.a=1,com.example.b=2` 的标签
- **THEN** 「标签」那一节里每个标签各占一组：先一行键名、紧接一行值
- **AND** 两组之间分得清，不挤成一整行

#### Scenario: CL-020 值里带逗号或括号不算拆行
- **WHEN** 某个标签的值里带着花括号与其中的逗号
- **THEN** 这串值仍完整落在它自己那一行，没被从中间拆开

#### Scenario: CL-021 一个标签都没有时给横杠
- **WHEN** 选中的容器没有任何标签
- **THEN** 「标签」这一节读得到一个"—"，不是一大片空白

### Requirement: wslc 说什么，界面说人话
wslc 的输出形态不止一种（每行一个对象 / JSON 数组 / 带缩进的整块 / 单个对象），
错误一律写在 stderr 且末尾挂着那句"欢迎提 issue"的样板话。
每一种形态都要读得进，套话要滤掉。

#### Scenario: CL-022 排版怎么变都读出同样的行
- **WHEN** 同一批容器被排成每行一个对象、JSON 数组、带缩进的整块 JSON 或单个对象
- **THEN** 界面列出的容器一种不多一种不少，字段也不缺

#### Scenario: CL-023 读不懂的行要说清是哪一行
- **WHEN** wslc 的输出里有一行不是有效的容器 JSON
- **THEN** 错误条读得到是第几行、以及那一行的原文片段
- **AND** 说的是"容器"这类数据读错了，不是含糊的一句"解析失败"

#### Scenario: CL-024 错误条丢掉样板话
- **WHEN** `wslc list` 以非 0 退出码失败，stderr 里写着错误描述、`错误代码:` 一行与那句"如果此错误是意外错误…"
- **THEN** 错误条读得到错误描述与 `错误代码:` 那一行
- **AND** 读不到那句样板话

#### Scenario: CL-025 stderr 是空的也要有话
- **WHEN** `wslc list` 非 0 退出但 stderr 一个字都没有
- **THEN** 错误条读得到"wslc 命令执行失败。"，不是一句空话

#### Scenario: CL-026 读失败不冲掉已经看见的列表
- **WHEN** 上一次刷新成功、这一次失败
- **THEN** 列表还是上一次那几行，一行的内容都没被清空
- **AND** 错误条同时挂出来，下次刷成功它就没了

#### Scenario: CL-027 这台机器上没有 wslc 时告诉用户怎么办
- **WHEN** 壳定位不到 wslc.exe，打开容器台
- **THEN** 界面读得到一句人话：要安装并启用 WSL 3，或在启动器的壳设置里指定 wslc.exe 的完整路径
- **AND** 应用不崩、不弹框，页签与其余部分照常，wslc 那侧一条命令都没收到
