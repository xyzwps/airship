# pdf

## Purpose
PDF 那一屏：书架只列 PDF，阅读界面只有翻页与缩放。
书目、封面、进度与墨读是同一份数据（判据见 `src/shared/library/specs/library.md`），这里只管 PDF 自己画出来的东西。
真出图的观感与性能归 `npm run shot`，不在这本册子里。

### Requirement: 书架上只列 PDF，但那份书是共用的
两个入口一份索引：这里筛 `format` 是 pdf 的那几本，别的归墨读。

#### Scenario: PD-001 顶上是「PDF」那句说明，列表里只有 PDF
- **WHEN** 共用索引里既有 PDF 也有一本 EPUB，打开 PDF 应用
- **THEN** 顶部读得到「与墨读共用同一个书架，这里只列 PDF」
- **AND** 列表里读得到那份 PDF 的标题，读不到那本 EPUB

#### Scenario: PD-002 书库里没有 PDF 时读得到那句空态
- **WHEN** 共用索引里一本 PDF 都没有
- **THEN** 界面读得到「还没有 PDF。点右上角导入一份。」
- **AND** 不出现空列表的骨架

#### Scenario: PD-003 每行念得出标题、页数与读到第几页
- **WHEN** 索引里有一份 3 页、上次读到第 2 页的 PDF
- **THEN** 那一行读得到「3 页」与「读到第 2 页」
- **AND** 那个页数与页码都来自共用索引，不是当场打开文档问出来的

#### Scenario: PD-004 移除要先确认，不确认就什么都不动
- **WHEN** 点某一行的「移除」，在确认框里回答"否"
- **THEN** 问的那句逐字是「从书架移除《说明书》？本地副本和封面会一起删掉。」
- **AND** 那一行还在列表里，索引与本地副本都没动

#### Scenario: PD-005 确认移除后索引与文件一起没了，别的不动
- **WHEN** 在确认框里回答"是"
- **THEN** 共用索引里不再有这个 id，它的本体与封面文件都不存在了
- **AND** 另一份 PDF 的记录与文件都还在

#### Scenario: PD-006 导入的标题取自文件名，页数与封面都落到共用索引里
- **WHEN** 选一份 `/桌面/年度报告.pdf` 导入
- **THEN** 新书的标题是「年度报告」（不带 .pdf），格式记为 pdf，附加信息里是文档报出的页数
- **AND** 本体副本在 `files/<书号>.pdf`，封面图在 `covers/<书号>.jpg`
- **AND** 书架那一行立刻读得到「3 页」

#### Scenario: PD-007 封面渲不出来也不挡导入
- **WHEN** 导入时第一页渲不出图（封面那一步失败）
- **THEN** 这份仍然登记成功，标题与页数都在，封面是空的
- **AND** 界面不报导入失败

### Requirement: 阅读那一栏只有必需的几个动作
回书架、翻页、缩放。缩放只在这次阅读里有效。

#### Scenario: PD-008 顶栏那颗「← 书架」回书架，并重新读到最新进度
- **WHEN** 翻到第 2 页后点「← 书架」
- **THEN** 界面回到书架，那一行读得到「读到第 2 页」

#### Scenario: PD-009 页码那一格念得出当前与总数，文档还没到位时总数也在
- **WHEN** 文档还压在半路上没到位
- **THEN** 页码那一格读得到「1 / 3」，总数用的是索引里登记的页数
- **AND** 这时按向右键也夹在同一个总数上，不会翻出个第 0 页

#### Scenario: PD-010 第一页时上一页点不动，最后一页时下一页点不动
- **WHEN** 打开一份 3 页的文档，再翻到最后一页
- **THEN** 在第 1 页时「上一页」是禁用态，「下一页」可点
- **AND** 到第 3 页后「下一页」变成禁用态，读得到「3 / 3」

#### Scenario: PD-011 键盘向右翻页，向左退回去，两头都夹住
- **WHEN** 用方向键与 PageUp / PageDown 翻一份 3 页的文档
- **THEN** 向右翻到 3 / 3 就停住，向左退回 1 / 3 也停住
- **AND** 页码那一格念出的始终是 1 到 3 之间的数

#### Scenario: PD-012 翻一页就把这一页写回共用的那本索引
- **WHEN** 从第 1 页翻到第 2 页
- **THEN** 共用索引里这本书的进度变成第 2 页（节号 1、比例 0、CFI 空、带更新时间）
- **AND** 墨读那边读同一份索引也看得到这一页

#### Scenario: PD-013 再打开时落在上次读到的那一页
- **WHEN** 上次读到第 3 页，这次重新打开同一份
- **THEN** 一进来读到的就是「3 / 3」，「下一页」是禁用态

#### Scenario: PD-014 缩放一档 25%，从 125% 起，两头都有界
- **WHEN** 打开文档后连点放大到顶，另一次连点缩小到底
- **THEN** 一进来读得到 125%，点一下 ＋ 变成 150%
- **AND** 缩到底读到 50% 且「−」禁用，放到底读到 400% 且「＋」禁用

#### Scenario: PD-015 缩放不进设置，换一次重开回到 125%
- **WHEN** 放大一档后关掉再重新打开同一份
- **THEN** 缩放那一笔从没写进设置（这个应用一次设置都没写过）
- **AND** 重新打开时又回到 125%

#### Scenario: PD-016 出图那会儿读得到「渲染中…」，出完就没了
- **WHEN** 一页正在出图
- **THEN** 界面上读得到「渲染中…」
- **AND** 这一页出完以后这句话消失，页面不是一片空白
