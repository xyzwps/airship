# dagogo

## Purpose
打勾勾：每天要做的事、勾掉就行。数据在应用自己的目录里，导出文件与手机版互读，
托盘上那几个字是今天勾掉的个数。界面文案与手机版同一套说法。

### Requirement: 本地数据只认自家的形状
本地文件是 `{ version: 1, tasks: [...] }`；形状不对就说不对，不猜、不静默清空。

#### Scenario: DG-001 还没有记录文件时读到空表，界面是空态
- **WHEN** 应用数据目录里还没有记录文件，打开打勾勾
- **THEN** 读到一张空表，界面读得到「还没有记录。上面写一件，回车就行。」
- **AND** 不出现任何报错文字

#### Scenario: DG-002 本地文件里 tasks 不是列表时报错文案原样上界面
- **WHEN** 本地文件写着 `"tasks": {"a": 1}` 这种形状，然后打开打勾勾
- **THEN** 界面读得到「读取失败：本地数据格式不正确」
- **AND** 原文件留在原地，不被改写掉

#### Scenario: DG-003 本地文件里混进不像待办的项，只留下像的
- **WHEN** 本地文件里四条记录，两条缺字段或字段类型不对
- **THEN** 界面只列得出那两条像样的（「买菜」「回电话」），另两条不出现也不报错

### Requirement: 导出与导入要和手机版互读
导出文件逐字带 `app: 打勾勾`，字段就那四个；导入按同一套规则归一化。

#### Scenario: DG-004 导出的文件逐字带上 app: 打勾勾 与四个字段
- **WHEN** 在数据面板点「导出到文件」并选一个位置
- **THEN** 那个文件里只有 `app` / `version` / `exportedAt` / `tasks` 四个键，`app` 是「打勾勾」，`version` 是 1
- **AND** `exportedAt` 是一个时刻，`tasks` 里带着当前这些条
- **AND** 界面回一句「已导出：打勾勾.json」

#### Scenario: DG-005 导出时没选地方就什么都不写
- **WHEN** 点「导出到文件」但在保存框里没选任何位置
- **THEN** 数据目录之外没有新文件，界面也不说"已导出"

#### Scenario: DG-006 裸数组与 {tasks: [...]} 两种都收
- **WHEN** 分别拿一份裸数组和一份带 `tasks` 字段的对象去归一化
- **THEN** 两种都得到同样的待办列表——手机版两种写法都出过

#### Scenario: DG-007 不像待办的与空标题的跳过，全跳光就说没有可导入的
- **WHEN** 导入的内容里混着空标题、缺字段、根本不是对象的条目
- **THEN** 只有像样的那条留下来，标题两侧的空格被去掉
- **AND** 一条都不剩时抛「文件里没有可导入的待办」

#### Scenario: DG-008 不是打勾勾的 JSON 就说清不是
- **WHEN** 选中的文件是一份别的 JSON（或根本不是对象）
- **THEN** 抛出的原因逐字是「文件不是打勾勾的 JSON 数据」

#### Scenario: DG-009 书号缺了或撞了都重排，一条都不少
- **WHEN** 导入的四条里有两条书号相同、一条书号是空的
- **THEN** 四条全进得来，四条的书号互不相同且都不为空

#### Scenario: DG-010 导入是追加，新导入的排在前面
- **WHEN** 已有记录的应用导入了手机版的两条
- **THEN** 本地文件里是三条，顺序是「从手机来的」「另一条手机来的」「原有的一条」
- **AND** 界面回一句「导入 2 条」

### Requirement: 今天算今天
换天判的是本机日历日；顶部那句只数今天勾掉的，分母是全部条数。

#### Scenario: DG-011 勾上写完成时间，取消抹掉不留历史
- **WHEN** 勾掉一件，再把它取消
- **THEN** 勾上时本地文件里那件的完成时间是一个时刻，"已完成"那一节多出它
- **AND** 取消后完成时间变回空，界面不再出现"已完成"那一节

#### Scenario: DG-012 顶部那句只数今天勾掉的，分母是全部条数
- **WHEN** 三条记录：今天勾掉一件、昨天勾掉一件、还没做一件
- **THEN** 顶部读得到「今天 1 / 3」
- **AND** 三条的录入日期都是三天前，与完成数无关

#### Scenario: DG-013 过了午夜算新的一天，昨天深夜勾掉的不进今天
- **WHEN** 判一个本地时刻是不是今天：今天 00:05 与今天 23:55 是，昨天 23:55 与明天 00:05 不是
- **THEN** 昨天深夜勾掉的那件在今日计数里不算，仍出现在「已完成」那一节
- **AND** 顶部读到的是「今天 0 / 1」

#### Scenario: DG-014 每行念得出录入与完成时间，今天发生的只报时刻
- **WHEN** 一件是前天录入、今天九点零六完成的
- **THEN** 那行读得到「X月X日 08:05 录入」这样的跨天写法
- **AND** 今天发生的这一段只报时刻，读得到「· 09:06 完成」

### Requirement: 界面默认只说今天要做什么
两节列表、一句鼓励语、一个输入框，别的不占地方。

#### Scenario: DG-015 写一件回车就进列表，界面读得出它
- **WHEN** 在输入框里写「给妈妈回电话」并按回车
- **THEN** 待办那一节出现这条，计数是 1，本地文件里也有它

#### Scenario: DG-016 待办与已完成两节各带计数，空的那节不出现
- **WHEN** 两条待办加一条已完成；换一份只剩一条待办的数据
- **THEN** 前者读得到「待办 2」与「已完成 1」两节
- **AND** 后者整节「已完成」都不出现，不是出现一个空的节

#### Scenario: DG-017 鼓励语点得开也改得掉，改后落进设置
- **WHEN** 点那句默认的「一件一件，慢慢来」，改成「先做最难的那件」并保存
- **THEN** 顶部念的是改后那句，设置里落的就是那句
- **AND** 背景那一项仍是空的，没被顺手改掉

#### Scenario: DG-018 删除要先确认，句子带标题原文；不确认就什么都不动
- **WHEN** 点某一条的「删除」
- **THEN** 问的那句逐字是「删除「买菜」？录入和完成时间会一起删掉。」
- **AND** 回答"否"时这条还在本地文件里；回答"是"时界面上读不到它，文件里也没了

#### Scenario: DG-019 没写字的时候添加那颗点不动
- **WHEN** 输入框是空的或只有一串空格
- **THEN** 「添加」是禁用态，敲进去真字以后才可点
- **AND** 点下去以后输入框清空，列表里只多这一条

### Requirement: 托盘上是今天的数
托盘替代手机版的桌面小组件：数字是今天勾掉的个数。

#### Scenario: DG-020 托盘提示文字念得出今天勾掉数与总数
- **WHEN** 打开打勾勾，两条里今天勾掉一条
- **THEN** 交给壳的提示文字逐字是「打勾勾 · 今天勾掉 1 个，共 2 条」
- **AND** 图标是渲染侧画好交上去的一张图，点击要唤回窗口

#### Scenario: DG-021 再勾一个，托盘上的数字跟着进一位
- **WHEN** 在界面里再勾掉一件
- **THEN** 提示文字变成「打勾勾 · 今天勾掉 2 个，共 2 条」

#### Scenario: DG-022 打勾勾的窗口关了，托盘跟着撤掉
- **WHEN** 打勾勾的界面被关掉
- **THEN** 壳那边的托盘状态被清空，不再占着那个图标
