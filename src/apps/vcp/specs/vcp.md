# vcp

## Purpose
vcp —— FFmpeg 编排台：打开一个媒体文件，挑要保留的流、勾处理链、看将要执行的那行命令，
把任务丢进串行队列。这本册子钉的是界面念得出什么、发给 ffmpeg 的命令行是什么形状、任务栏里念得出什么。
窗口、主题、能力闸门、路径授权与 proc 白名单归壳（`src/shell/specs/`），不在这里重复。

> 真素材与真编码那一档（`VCP_E2E=1 npx vitest run e2e`）要本机 ffmpeg 与素材才跑，
> 默认跳过；实测数据记在 [架构](../../../../docs/architecture.md) §3.1。

### Requirement: 打开文件就是问 ffmpeg 一句话，答案念到顶栏上
探测与转码只走壳发现的那一个 ffmpeg（依据：[架构](../../../../docs/architecture.md) §6.3 工具表与 proc 白名单）。

#### Scenario: VC-001 探测就问 ffmpeg 一句话：-hide_banner -i <文件>
- **WHEN** 点「打开视频」并选中一个媒体文件
- **THEN** 交给壳执行的是壳发现的那个 ffmpeg，参数逐字三条：`-hide_banner`、`-i`、所选文件的路径
- **AND** 探测这一步不写出任何输出文件

#### Scenario: VC-002 顶栏念得出时长、格式、码率、大小与流数
- **WHEN** 打开一份 4K 的 `4k_demo.mkv`
- **THEN** 顶栏读得到文件名 `4k_demo.mkv`，还有「00:01:40.00」「matroska」「5000 kb/s」「2.0 MB」「6 条流」
- **AND** 「还没打开视频」那句不再出现

#### Scenario: VC-008 选流列表里认得出封面流与图形字幕
- **WHEN** 打开一份带封面图与蓝光图形字幕轨的文件
- **THEN** 视频那组读得到「v:0 hevc 3840x2160 25fps」，封面那条带着「（封面）」字样
- **AND** 字幕那组里图形轨带着「（图形）」字样，文字轨不带

#### Scenario: VC-051 打开视频后输出路径自动落在源文件同目录
- **WHEN** 打开 `T:/media/4k_demo.mkv`
- **THEN** 「输出到」那一栏已经是 `T:/media/4k_demo.mp4`（同目录、主名不变、后缀跟着容器走）

#### Scenario: VC-052 什么视频都没打开时界面说的话
- **WHEN** 刚进 vcp，还没选过任何文件
- **THEN** 顶栏读得到「还没打开视频」，选流区读得到「打开视频后在这里选视频 / 音频 / 字幕轨。」
- **AND** 「批量套用」与「提交任务」都点不动，右栏读得到「队列空」与「队列是空的。」

#### Scenario: VC-069 ffmpeg 不可用时顶栏那枚与硬开视频的原因
- **WHEN** 这台机器上没有可用的 ffmpeg，点「打开视频」
- **THEN** 顶栏那枚读得到「ffmpeg 不可用」，点完之后错误条原样是「没找到 ffmpeg」
- **AND** 界面上不出现 `Error invoking remote method` 这类壳的内部措辞

### Requirement: 保留哪些流，决定命令里的 -map / -vn / -an
命令用的是同类型内的相对序号（`0:v:0`、`0:a:1`），不是 ffmpeg 报出来的全局流号。

#### Scenario: VC-009 不要画面就 -vn，不要声音就 -an
- **WHEN** 视频选「不要视频」，音频一条都不勾
- **THEN** 命令里出现 `-vn` 与 `-an`，且一条 `-map` 都不出现
- **AND** 只去掉音频、保留画面时是 `-map` 加 `-an`，不出现 `-vn`

#### Scenario: VC-010 保留音频的条数决定有几条 -map 0:a
- **WHEN** 保留画面并勾上两条音频
- **THEN** 命令里一共三条 `-map`，音频那两条写作 `0:a:0` 与 `0:a:1`

#### Scenario: VC-011 内嵌软字幕的 map 是同类型相对序号
- **WHEN** 勾上一条内嵌文字字幕并把字幕方式留在软字幕
- **THEN** 命令里出现 `-map 0:s:0`

#### Scenario: VC-012 外挂字幕按 -i 出现的顺序编号，map 用的是那个输入序号
- **WHEN** 挂两份外挂 srt，只勾第二份
- **THEN** 命令里一共三个 `-i`：源文件在最前，两份外挂依次跟在后面
- **AND** 选中的那份写作 `-map 2:s:0`，不出现 `1:s:0`

#### Scenario: VC-013 图形字幕在 mkv 里只能原样复制
- **WHEN** 保留一条蓝光图形字幕，容器选 mkv，方式是软字幕
- **THEN** 字幕编码器是 `-c:s copy`
- **AND** 图形轨与文字轨混在同一条命令里时逐轨指定：`-c:s:0 copy`、`-c:s:1 srt`

### Requirement: 处理链只把开着的开关写进命令
顺序与 ffmpeg 滤镜的写法是外部契约：缩放、补边、色彩、水印、帧率。

#### Scenario: VC-014 开关开着的才进 -vf，顺序是缩放、补边、色彩、水印、帧率
- **WHEN** 只开缩放（1280×-2）、色彩与帧率 30
- **THEN** 命令里逐字是 `-vf scale=w=1280:h=-2,eq=brightness=0:contrast=1:saturation=1,fps=fps=30`
- **AND** 一颗开关都不开时，命令里根本没有 `-vf`

#### Scenario: VC-015 快速定位把 -ss 放在输入之前，慢定位放在之后，-to 总在输入之后
- **WHEN** 裁剪 00:01:00 → 00:02:30，勾着「快速定位」
- **THEN** `-ss` 出现在第一个 `-i` 之前，`-to` 出现在 `-i` 之后
- **AND** 取消「快速定位」后 `-ss` 挪到 `-i` 之后，并且整个命令里只出现一次

#### Scenario: VC-016 滤镜里的路径是正斜杠、冒号转义、单引号包住
- **WHEN** 滤镜参数里带一个 Windows 路径（`T:\字幕\第一份.srt`、`C:/Windows/Fonts/msyh.ttc`）
- **THEN** 写成 `'T\:/字幕/第一份.srt'` 与 `'C\:/Windows/Fonts/msyh.ttc'`（反斜杠换正斜杠、冒号前加反斜杠、整体单引号）
- **AND** 烧一份带空格的外挂字幕时，命令里读得到 `subtitles=filename='C\:/字幕 第一.srt'`

#### Scenario: VC-017 水印默认字体与四角位置
- **WHEN** 开文字水印，内容是「我的水印」，位置选「右上」
- **THEN** 滤镜里有 `drawtext=text='我的水印'`，字体逐字是 `'C\:/Windows/Fonts/msyh.ttc'`
- **AND** 位置那截写作 `x=w-tw-24:y=24`

#### Scenario: VC-018 音量与响度串成两个滤镜，但一条音频都没留时不发 -af
- **WHEN** 音量倍率填 2 并同时开响度归一
- **THEN** 命令里是 `-af volume=2,loudnorm=I=-16:TP=-1.5:LDI=11`
- **AND** 把音频全去掉后，命令里不再出现 `-af`

### Requirement: 编码档位、容器与默认输出名各有各的条件
`-crf` / `-cq` 与编码器挂钩，输出名的规则是用户认得出的那一截。

#### Scenario: VC-019 nvenc 用 -cq，x264 这类用 -crf，直接复制两个都不给
- **WHEN** 质量填 23，编码分别选 `libx264`、`hevc_nvenc`、`copy`
- **THEN** `libx264` 得到 `-crf 23` 且没有 `-cq`；`hevc_nvenc` 得到 `-cq 23` 且没有 `-crf`
- **AND** 选 `copy` 时 `-crf`、`-cq`、`-preset` 一个都不出现

#### Scenario: VC-020 像素格式与 faststart 各自的条件
- **WHEN** 容器 mp4、画面重编码
- **THEN** 命令里有 `-pix_fmt` 与 `-movflags`
- **AND** 画面改直接复制时两个都没有；容器换 mkv 时 `-movflags` 没有；不保留画面时 `-pix_fmt` 没有

#### Scenario: VC-021 音频码率只在重编码音频时给，附加参数排在输出路径之前，输出路径永远最后一位
- **WHEN** 附加参数填 `-max_muxing_queue_size 1024`
- **THEN** 音频重编码时命令里有 `-b:a 192k`，音频选直接复制时没有 `-b:a`
- **AND** 附加参数原样进命令，且最后一个参数是输出路径（那一栏空着时末位是 `out.mp4`）

#### Scenario: VC-022 命令行显示：带空格或引号的参数加双引号，里面的引号要转义
- **WHEN** 看界面「命令」那一行念出的参数
- **THEN** 带空格的路径写作 `ffmpeg -i "T:/a b.mp4"`，不需要引号的参数直接空格相接：`ffmpeg -y -an`
- **AND** 参数内部的双引号转义成 `\"`（`drawtext=text='说"唱"'` 念出来是 `"drawtext=text='说\"唱\"'"`）

#### Scenario: VC-023 输出名里的高度：写了按写的，留 -2 按源算偶数高，读不到源信息回落 1080
- **WHEN** 缩放 1280×720 或 1280×-2，源是 3840×2160
- **THEN** 默认输出名分别是 `片源_720p.mp4` 与 `片源_720p.mp4`
- **AND** 源高是奇数（3840×2177）折 1000 宽时得到 `片源_566p.mp4`，仍是偶数
- **AND** 没保留画面（读不到源尺寸）时回落成 `片源_1080p.mp4`；没开缩放时名字里不带 `_NNNp` 那一截

#### Scenario: VC-074 输出名跟着配置走：缩放那一截自己长收，后缀永远跟着容器换
- **WHEN** 打开 `T:/media/4k_demo.mkv` 后开缩放（1920×-2，源 3840×2160），再关掉，再把容器换成 mkv
- **THEN** 「输出到」那一栏依次是 `T:/media/4k_demo_1080p.mp4`、`T:/media/4k_demo.mp4`、`T:/media/4k_demo.mkv`
- **AND** 手敲过名字之后主名不再被覆盖，但换容器时后缀照样跟着换：`我起的名字.mp4` 换 mkv 成 `我起的名字.mkv`

### Requirement: 检查区念得出问题在哪，能一键修的就给一键
每条提示是一句中文原话；error 挡住执行，warn 与 info 只提醒（依据：[架构](../../../../docs/architecture.md) §11）。

#### Scenario: VC-025 还没打开视频时只念那一句
- **WHEN** 什么都没打开就去看检查区
- **THEN** 只有「还没有打开视频。」这一条，别的一句都不念

#### Scenario: VC-026 没填输出路径
- **WHEN** 「输出到」那一栏被清空
- **THEN** 检查区读得到「没填输出路径。」

#### Scenario: VC-027 一条流都没保留
- **WHEN** 视频选「不要视频」且音频一条都不勾
- **THEN** 检查区读得到「一条流都没保留，输出会是空文件。」

#### Scenario: VC-028 音频直接复制却要加音量：报 error 并给"改用 aac"
- **WHEN** 音频编码选「直接复制」，同时开着音量
- **THEN** 检查区读得到「音量/响度滤镜需要重编码音频，当前音频是直接复制。」，旁边一枚「改用 aac」
- **AND** 按那枚改完之后这一条消失

#### Scenario: VC-029 音量与响度同开只是提醒，不挡执行
- **WHEN** 音量与响度归一同时开着
- **THEN** 检查区读得到「音量和响度归一同时开，归一会盖过手动倍数。」
- **AND** 这一条旁边没有一键修正的按钮

#### Scenario: VC-030 结束时间不晚于开始时间就报错，两个时间相等也算
- **WHEN** 裁剪填 00:02:00 → 00:01:30，或填 00:02:00 → 00:02:00
- **THEN** 检查区读得到「结束时间早于开始时间。」
- **AND** 结束时间改成 00:02:01 后这一条消失

#### Scenario: VC-031 输出已存在：念出大小，一键"另存为新名"换个名字
- **WHEN** 输出路径上已经躺着一个 5.0 MB 的文件
- **THEN** 检查区读得到「输出文件已存在（5.0 MB），执行会直接覆盖。」，旁边一枚「另存为新名」
- **AND** 那个位置不存在文件时这一条不出现

#### Scenario: VC-032 输出与源同名（大小写与斜杠不同也算）
- **WHEN** 输出写成 `t:\media\片源.mp4`，源是 `T:/media/片源.mp4`
- **THEN** 检查区读得到「输出路径与源文件相同，会毁掉源文件。」

#### Scenario: VC-075 手敲的后缀与容器不符：念出来说清产物会是哪一个，并给一键
- **WHEN** 容器是 mp4，「输出到」写成 `T:/media/片源.avi`
- **THEN** 检查区读得到「输出名后缀是 .avi，容器选的却是 mp4：ffmpeg 按后缀认容器，产物会是 .avi。」，旁边一枚「换成 .mp4」
- **AND** 按完之后那一栏是 `T:/media/片源.mp4`，这一条消失

### Requirement: 字幕与容器怎么搭配，检查区提前把话说明白
图形字幕转不了也烧不进画面，这是 ffmpeg 的硬限制，界面上提前念出来。

#### Scenario: VC-038 mp4 装文字软字幕只是提醒，一键换成 mkv
- **WHEN** 保留一条文字软字幕，容器还是 mp4
- **THEN** 检查区读得到带 `mov_text` 的那句提醒，旁边一枚「换成 mkv」
- **AND** 这一条不是 error：读不到「装不下」那句报错

#### Scenario: VC-039 烧内嵌字幕前会先抽成临时文件，这条写给用户看
- **WHEN** 选中一条内嵌文字字幕并把字幕方式改成「烧进画面」
- **THEN** 检查区读得到「先抽成临时 srt」那句说明

#### Scenario: VC-040 源是 4K 又没开缩放，提醒 CPU 编码会慢
- **WHEN** 源是 3840×2160，缩放开关没开，画面重编码
- **THEN** 检查区读得到「源是 4K 又没开缩放，CPU 编码会非常慢。」，旁边一枚「开启缩放」
- **AND** 开了缩放后这一条消失

#### Scenario: VC-041 一处问题都没有时不产生任何提示
- **WHEN** 1080p 源、输出是个还不存在的新名字、字幕一条不选、处理链一颗都不开
- **THEN** 检查区一条提示都不产生

### Requirement: 队列里每一条的状态与进度都念得出来
状态话术与进度算法对用户可感知；ffmpeg 用 `-progress pipe:1` 往标准输出打 key=value 行。

#### Scenario: VC-042 六种状态各念各的那句
- **WHEN** 队列里分别有刚提交、已起跑（42%）、跑完（写出 5.0 MB）、砸了、被停、被取消的任务
- **THEN** 状态那一列依次念「排队中」「启动中」「进行中 42%」「已完成 5.0 MB」「失败」「已停止」「已取消」

#### Scenario: VC-043 进行中那一栏念得出倍速、还剩多久与已用多久
- **WHEN** 一条跑到 50%、倍速 2.50x、已跑 10 秒
- **THEN** 第二行念得出「2.50x」「约剩 0:10」与「已用 10 秒」
- **AND** 刚起跑（1%）还估不出剩余时，只念「已用 1 秒」

#### Scenario: VC-044 失败那一栏念最后一行报错，一句报错都没有就念"失败"
- **WHEN** 一条任务的报错是多行文本
- **THEN** 第二行念最后一行有字的：`error: 输出写不进去`
- **AND** 报错全是空行时念「失败」；排队中的那条则原样念它提交时写下的说明（如「输出撞名，改名 片源_2.mp4」）

#### Scenario: VC-055 进度按 out_time 折算，封顶 99.5，看到 end 才算完
- **WHEN** 一条 100 秒的任务依次报出 `out_time=00:00:50.000000`、`speed=3.20x`、`out_time=00:05:00.000000`
- **THEN** 百分比先是 50，倍速念「3.20x」，超出源时长后停在 99.5 不越界
- **AND** 报来 `frame=123` 这类与时间无关的行不改百分比；`progress=end` 才到 100
- **AND** `out_time=00:00:00.000000` 不算进度，百分比维持原样

### Requirement: 提交与批量：把界面上的配置冻结成任务
快照一次成型，之后界面怎么改都不影响已提交的那条；撞名自动让路（依据：[架构](../../../../docs/architecture.md) §7.5）。

#### Scenario: VC-056 还没打开视频就提交，说的是这一句
- **WHEN** 什么都没打开就提交
- **THEN** 得到「还没打开视频。」，队列里不多出任务

#### Scenario: VC-057 字幕还没抽出来就提交，说稍一下再提交
- **WHEN** 选中内嵌字幕要烧进画面，但那份临时 srt 还没抽好
- **THEN** 得到「字幕还没抽出来，稍一下再提交。」，这条不入队

#### Scenario: VC-058 提交后的输出名撞了队列里的名字，改名与说明都写在任务上
- **WHEN** 同一份配置连提两次，输出都是 `T:/media/同名.mp4`
- **THEN** 第二条的输出换成 `T:/media/同名_2.mp4`，说明写着「输出和队列里已有的撞名，改名 同名_2.mp4」
- **AND** 它那一串参数的最后一位跟着换成新名字

#### Scenario: VC-059 批量：视频与音频按目标文件重选，配不上的字幕写进说明
- **WHEN** 带着「简体中文」字幕的配置套用到一个只有 1080p 画面、英文音频、没有中文字幕轨的文件
- **THEN** 这条按目标文件重选：画面 0、音频 0，字幕一条都不保留
- **AND** 说明里写着「没找到「简体中文」对应的字幕轨，这个文件不带字幕」

#### Scenario: VC-060 批量时目标文件连正片视频都没有，说明里写这一句
- **WHEN** 批量套用的目标只有一条音频轨
- **THEN** 这条不保留画面，说明里读得到「没有正片视频流」

#### Scenario: VC-061 撞名的输出排到 _3，没人占着的名不改
- **WHEN** `T:/a.mp4` 与只差大小写的 `T:/A_2.mp4` 都已经在队列里
- **THEN** 新的 `T:/a.mp4` 让到 `T:/a_3.mp4`
- **AND** 没被占着的 `T:/b.mp4` 原样不动

### Requirement: 命令、检查与一键修正都在同一屏上
底部那行命令就是将要执行的参数，改哪里它跟着变（依据：[架构](../../../../docs/architecture.md) §10）。

#### Scenario: VC-062 一键修正在界面上点得动：画面选了复制时那句改完命令跟着变
- **WHEN** 开着缩放又把视频编码选成 `copy`
- **THEN** 命令里是 `-c:v copy`，检查区读得到「视频不能选“直接复制”」，旁边一枚「改用 x264」
- **AND** 点那枚之后命令变成 `-c:v libx264`，那句话从检查区消失

#### Scenario: VC-063 命令那一行就是将要执行的参数，随界面改动走
- **WHEN** 打开 `T:/media/4k_demo.mkv` 后看「命令」那一行
- **THEN** 读得到 `ffmpeg -y -i T:/media/4k_demo.mkv`、`-map 0:v:0`，末尾是输出路径
- **AND** 把处理链第一颗开关（缩放）打开，这一行立刻多出 `-vf scale=w=1920:h=-2`

#### Scenario: VC-064 检查里有 error 时提交点不动，改回能保留的流就能提交
- **WHEN** 视频选「不要视频」再取消唯一的音频
- **THEN** 检查区读得到「一条流都没保留，输出会是空文件。」，「提交任务」是点不动的
- **AND** 把那条音频重新勾回去，「提交任务」就能点了

#### Scenario: VC-068 复制命令：剪贴板里是那一行，按钮改口说"已复制"
- **WHEN** 点「复制命令」
- **THEN** 剪贴板里的内容逐字就是界面那一行命令
- **AND** 那颗按钮改口读作「已复制」

### Requirement: 任务跑起来之后，右栏的队列念得出来
一次只跑一条，跑完自动接下一条；停止与清掉完成各管各的（依据：[架构](../../../../docs/architecture.md) §6.3 流式任务）。

#### Scenario: VC-065 提交后右栏出现 #1，壳收到的命令行带着进度管道
- **WHEN** 打开视频后点「提交任务」
- **THEN** 右栏出现 `#1` 与源文件名 `4k_demo.mkv`
- **AND** 交给壳执行的参数前四位是 `-hide_banner -nostats -progress pipe:1`，最后一位是输出路径

#### Scenario: VC-066 进行中：状态与速度念得出壳推来的那一截
- **WHEN** 这条任务报回 `out_time=00:00:50.000000` 与 `speed=2.35x`
- **THEN** 状态念「进行中 50%」，第二行念得出「2.35x」与「已用」
- **AND** 这一条带着「停止」那颗键

#### Scenario: VC-067 跑完：状态念得出"已完成"与实际写出来的大小
- **WHEN** 任务报出结束并以退出码 0 收尾，输出位置上真有一个 2.0 MB 的文件
- **THEN** 状态念「已完成 2.0 MB」，汇总念得出「完成 1」
- **AND** 这一条带着「移除」那颗键

#### Scenario: VC-070 跑砸了：状态念"失败"，第二行念最后一句报错
- **WHEN** 任务的错误输出里有 `[libx264] error: 写不进去`，最后以退出码 1 结束
- **THEN** 状态念「失败」，第二行念得出「error: 写不进去」
- **AND** 汇总念得出「失败 1」

#### Scenario: VC-071 全部停止：在跑的念"已停止"，排队的念"已取消"
- **WHEN** 两条任务（一跑一排队，汇总「进行中 1 · 排队 1」）时点「全部停止」
- **THEN** 在跑的那条状态念「已停止」，排着的那条念「已取消」

#### Scenario: VC-072 批量套用：两个文件各成一条，撞名的自动改名并写在说明里
- **WHEN** 带着当前配置点「批量套用」并选中两个文件（其中一个的输出与另一条撞名）
- **THEN** 右栏各成一条 `#1` 与 `#2`，撞名的那条输出是 `4k_demo_2.mp4`
- **AND** 它的说明念得出「改名 4k_demo_2.mp4」

#### Scenario: VC-073 两条任务排队时汇总分项念得出来，跑着的那条不被"清掉完成"带走
- **WHEN** 两条任务（一条在跑一条排队）时点「清掉完成」
- **THEN** 汇总还是「进行中 1 · 排队 1」，两条都留在右栏
- **AND** 在跑的那条以退出码 0 结束后，汇总念「进行中 1 · 完成 1」——排着的那条自动接上跑
