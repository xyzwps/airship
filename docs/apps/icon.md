# 一个 app 的图标要求

一个应用**固定两张图标**，都放应用目录根（产包后就是包根），文件名靠约定：

| 文件 | 格式 | 给谁用 | 用在哪 |
| --- | --- | --- | --- |
| `icon.png` | **只认 PNG** | 窗口内部 | 标题栏左上角那枚 15×15 记号 |
| `icon.ico` | 多尺寸 ICO | Windows 外壳 | 任务栏按钮、桌面/开始菜单快捷方式——外壳只认**文件系统路径**，不认 asar 也不认 `airship://` |

两张都由作者**存成文件**随仓库走：产包只搬进包根，**全仓任何环节都不转图标格式**。改了源图要在外部工具里重出那张 `.ico`。

## `icon.ico` 的标准形状

7 帧方图 **16 / 24 / 32 / 48 / 64 / 128 / 256**，每帧 32 位色、帧内 **PNG 压缩**（不是老式 BMP + AND 掩码）。
给作者的下限是 **16 / 32 / 48 / 256 齐**；帧数不齐、尺寸不成套，产包不拦。源图建议 ≤512×512，不套底板，颜色烘进图里。

## 判据边界

- 代码判据只有一份：`@airship/contract` 的 `packageRules.ts`（`ICON_NAME` / `ICON_PATTERN` / `RETIRED_ICON_PATTERN` / `WINDOWS_ICON_NAME`）——产包侧与注册侧调同一批函数，报错措辞也由它供，别在界面或 NSI 里另写一份。
